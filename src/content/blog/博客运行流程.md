### **阶段一：写作与本地预览（本地阶段）**

1. **写文章的地方**：
    - 博客的所有 Markdown 文章存放在 `src/content/blog/` 目录下；
    - 你可以直接在 VS Code 里编写，也可以直接用 **Obsidian** 打开该文件夹书写。
2. **本地实时预览**： 在编写过程中，你可以随时在项目根目录启动本地开发环境：
    powershell
    astro dev --background   # 后台启动本地服务器
    - 浏览器打开 `http://localhost:4321`，你修改保存 Markdown 时，浏览器会**即时热更新**预览效果；
    - 预览完毕后可运行 `astro dev stop` 停止。

### **阶段二：一键全自动发布（CI/CD 构建阶段）**
```powershell
git add .
git commit -m "post: 发布新文章"
git push
```
**此时云端会自动发生以下事情**：
1. **触发信号**：GitHub 接收到你的 `git push`，立刻向 Vercel 发送通知（Webhook）；
2. **云端打包**：Vercel 在几秒内启动一台云端轻量容器，拉取你的最新代码，自动运行 `npm run build`；
3. **Astro 编译**：Astro 引擎扫描 `src/content/blog/` 下所有 `draft: false` 的文章，将它们转化为**纯静态的 HTML、CSS、JS 文件**；
4. **全自动发布**：Vercel 将生成的静态文件推送到全球 CDN，**整个过程只需 20~30 秒**！你完全不需要碰服务器。

任意powershell直接一键执行
```
cd C:\myblog; git add .; git commit -m "更新文章"; git push; npm run build; scp -P 22 -r dist/* root@120.27.245.127:/opt/1panel/apps/openresty/openresty/www/sites/blog.limits.cc.cd/index/
```
